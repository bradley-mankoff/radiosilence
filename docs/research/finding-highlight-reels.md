## 4. Data API quota: playlistItems list costs 1 unit, search list has its own 100 call bucket

The official search list reference at https://developers.google.com/youtube/data/reference/rest/v3/search/list states quota impact as 100 calls per day with a quota cost of 1 unit in the Search Queries quota bucket, verified by fetching the page on October 25, 2026. The official playlistItems list reference at https://developers.google.com/youtube/data/reference/rest/v3/playlistItems/list states a quota cost of 1 unit with no separate bucket, verified the same day. The official quota cost table at https://developers.google.com/youtube/data/determine_quota_cost states that projects enabling the YouTube Data API get a default allocation of 100 search.list calls, 100 videos.insert calls, and 10,000 units per day combined for all other endpoints, and its method table lists playlistItems list at 1 and search list at 100 quota per day with each call costing 1 quota. For this app the arithmetic is simple: polling one uploads playlist per cycle with playlistItems list costs about 1 unit per game per night from the 10,000 unit pool, while one search list call per game draws from a 100 call bucket shared with nothing else the app needs. Recommendation: use playlistItems list on the uploads playlist as the API path if scraping ever breaks, and reserve search list for one time backfills only.
